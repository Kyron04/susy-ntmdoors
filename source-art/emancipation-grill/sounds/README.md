# Emancipation Grill sounds

Source: `https://github.com/sourcesounds/portal2`

The mod uses these Portal 2 fizzler assets, converted to OGG Vorbis:

| Portal 2 source | Mod asset | Use |
|---|---|---|
| `sound/vfx/fizzler_start_01.wav` | `sounds/emancipation/fizzler_start.ogg` | Field activates |
| `sound/vfx/fizzler_lp_01.wav` | `sounds/emancipation/fizzler_loop.ogg` | Active field loop |
| `sound/vfx/fizzler_shutdown_01.wav` | `sounds/emancipation/fizzler_shutdown.ogg` | Field deactivates or pair breaks |
| `sound/props/material_emancipation_01.wav` | `sounds/emancipation/disintegrate.ogg` | Lethal contact/disintegration |

The unused `sound/vfx/fizzler_vortex_lp_01.wav` is available if a separate vortex/alternate field loop is wanted later.

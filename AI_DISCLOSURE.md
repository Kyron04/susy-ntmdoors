# AI Assistance Disclosure

This file records how AI assistance was used in this repository, so users, pack maintainers and
downstream redistributors can judge the contribution.

## Tool and model

- **Agent:** OpenCode coding agent
- **Model:** DeepSeek V4.1 Flash
- **Session:** supervised by the repository owner, NeoRussia

## Scope of AI assistance

AI assistance was used for:

- the concrete metadata refactor: grouping cube and slab textures into metadata families,
  generating the slab `variant` / `half` blockstates, and keeping the block id count low;
- the HL Blocks integration: simple blocks, metadata groups, shift-scroll cycling, ore dictionary
  registration and Chisel carving groups;
- the concrete recipes and the `concrete` / `blockConcrete` ore dictionary registration;
- debugging the single-slab model lookup and reordering the slab blockstate keys to
  `half=...,variant=...`;
- the Thermite Charge integration: the supplied 3D model and sprite, face-inset mounting, fuse,
  breach and sound/particle logic, and the matching door breach rendering and collision;
- the Redstone Gate relay linking: gate-to-gate and gate-to-door sessions, mirrored outputs and
  door redstone integration;
- the Redstone Monocle: its supplied 16x16 sprite, the client-side wireless-link overlay, and the
  owner-only security-door Redstone toggle;
- the Spatial Disrupter creative-break exception;
- a Creative Relay Key prototype that was removed before release at the owner's request;
- final housekeeping: asset reference validation, stale comment cleanup and release docs;
- this disclosure and the concrete/HL Blocks section of `README.md`.

## What was not generated by AI

- No textures, models, sounds or other media in this repository were generated by AI. The door and
  concrete assets come from HBM's Nuclear Tech Mod / NTM CE, and the HL Blocks assets come from
  NeoRussia's HL Blocks project, as listed in `NOTICE`.
- No AI co-author trailers are added to commits. Git history records the human author only.

## Human review

NeoRussia reviewed the AI-assisted changes, built the mod with the repository's Gradle setup, and
tested the concrete, slab, stair, Chisel, ore dictionary, recipe, HL Block, Thermite Charge and
door-breach behaviour in game, including the slab model fix. The repository owner owns the code,
can explain it, and is responsible for supporting it.

If you redistribute this mod or a pack containing it, keep this disclosure with the sources.

NTM Doors includes assets copied from HBM's Nuclear Tech Mod.

Source: https://github.com/HbmMods/Hbm-s-Nuclear-Tech-GIT
Assets copied: multiblock door OBJ models, door textures, the vault label, and door sound effects.
License: GNU Lesser General Public License v3.0 (see LICENSE.LESSER in this JAR).

The concrete building set is derived from HBM's Nuclear Tech Mod Community Edition (NTM CE):
  https://github.com/Warfactory-Official/Hbm-s-Nuclear-Tech-CE
Assets copied: concrete textures under assets/ntmdoors/textures/blocks/
(concrete*, brick_concrete*, concrete_pillar_*, concrete_rebar.png).
Block names, metadata order, material values, recipe layout and the Über Concrete decay behaviour in
com.ntmdoors.concrete follow the same source.
License: GNU Lesser General Public License v3.0.

The Java implementation in com.ntmdoors is a standalone 1.12.2 port and keeps the original
door behaviour and asset layout where practical.

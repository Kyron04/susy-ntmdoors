# NTM Doors 1.0.36 sweep and stress test

Date: 2026-11-06

## Scope

This pass covered the whole mod: source audit, dead-code/asset checks, build hygiene, a
dedicated-server stress run, the terminal backup/restore paths, Security net event enforcement,
desk break/drop behaviour, and a production-jar client startup.

## Server stress results

The test harness forced 100 chunks and placed 1,024 six-monitor desks (9,216 blocks, one terminal
tile entity per desk) plus 200 devices (motion sensors, speakers, and Redstone Gates).

| Run | Mean tick time | TPS |
|---|---:|---:|
| Idle baseline | 0.045 ms | 20.000 |
| 1,024 desks, immediately after placement | 0.681 ms | 20.000 |
| 1,024 desks, steady state | ~0.05 ms | 20.000 |
| 1,024 desks + 200 devices | 0.208–0.231 ms | 20.000 |
| After save/restart | 0.200–0.219 ms | 20.000 |

- Desk placement: 1,024 desks in 0.03 s through the server API.
- World region size after save: 6.91 MB.
- Full server restart with the field: `Done (1.158 s)`; no exceptions.
- Breaking one cell dismantled the full 3x3 desk; the neighbouring desk stayed intact.
- Breaking a desk core dropped its two stored Terminal Backup Keys; no key loss.

## Functional self-test

The temporary harness ran these checks on a live dedicated server and reported `PASS`:

- Terminal backup upload and restore: nets, notepad text, and per-screen wallpaper restored.
- Backup-key copy: source key copied onto a blank key.
- Terminal NBT round-trip: a saved desk read back with the same net and document counts.
- Security net `System Lockdown`: scanner and door both reported lockdown; `request(true)` was
  blocked while it was active and opened the door once it was cleared.
- Programmer palette: 19 cards (seven colours, five Tarkov, six SCP, Googa).

## Fixes made during the sweep

- The 6 Monitor Setup now drops its stored Terminal Backup Keys when any cell is broken.
- Linking or unlinking a terminal key now syncs the physical monitors immediately.
- Idle monitor desks skip their six-screen tick loop; 1,024 idle desks are effectively free to tick.
- Notepad line wrapping no longer measures a growing substring for every character, removing the
  quadratic cost on long lines.
- Net-wide lockdown now blocks keypads, scanners, redstone and per-scanner override requests, not
  just closing doors every 16 ticks.
- Fixed a dedicated-server `NoSuchFieldError` in the speaker caused by initialised `@SideOnly`
  fields being stripped by Forge.
- URL wallpaper downloads now use two daemon workers instead of one thread per URL; dynamic
  textures and sensor overlays are released on world unload.
- Terminal passwords can only be set/skipped once; an existing password can no longer be
  overwritten by a repeat setup packet.
- Middle-clicking any monitor cell picks the desk item; upper cells no longer pick an itemless
  block.
- Removed the temporary stress harness and rebuilt the reobfuscated jar from clean sources.

## Client check

The production jar was started in the Supersymmetry(2) instance. The client reached the main menu
and reported `Sound engine started` with no NTM Doors exception or crash report. The only NTM
Doors-related log lines were the pre-existing libnine item-model probe warnings for
`biometric_safe`, `monitor_setup`, and `speaker`; these are third-party fallback messages and the
models render normally. Client FPS in a heavily built world was not measured separately.
